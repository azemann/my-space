# Scènes de lancement

Ces scènes assemblent un décor de niveau avec le joueur et l'interface minimale
nécessaire au test. Elles peuvent être lancées directement avec **F6**.

- `niveau-01.tscn` : scène principale du projet ;
- `niveau-02.tscn` : test direct du niveau 2 ;
- `niveau-03.tscn` : test direct du niveau 3.
- `niveau-04.tscn` : test solo du parkour d'arène ; le multijoueur reste à brancher.

Les décors seuls restent dans `scenes/levels/`.
