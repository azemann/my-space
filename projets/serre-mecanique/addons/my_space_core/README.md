# My Space Core

Briques Godot sans dépendance envers Serre mécanique : profils de caméra et de
personnage, définition d'un niveau, niveau natif et base d'équipement.

Ce dossier peut être copié dans un autre projet. Il ne doit jamais référencer
`game/serre/`, un niveau, un tileset ou un asset propre au jeu.
