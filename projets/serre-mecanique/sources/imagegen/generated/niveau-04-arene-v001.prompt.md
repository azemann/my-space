# Niveau 4 — tileset d'arène v001

Mode : génération intégrée ImageGen, cas `stylized-concept`.

Références :

1. grille de composition obligatoire 16 × 5 ;
2. tileset validé du niveau 1 pour les rôles et raccords.

Direction : arène d'essais de graines abandonnée pour deux à quatre joueurs,
avec terre renforcée, béton sombre, acier riveté, plateformes de sécurité,
cuivre, liquide cyan, caisses, barils explosifs et balises colorées.

La sortie ImageGen est une source artistique. Le fichier chargé par le projet
est construit par `sources/imagegen/build_level_04_arena_tileset_v001.py`.
