# Niveau 2 — étude ImageGen v002

Mode : édition intégrée ImageGen, cas `precise-object-edit`.

Références :

1. le tileset du niveau 1, gabarit géométrique obligatoire ;
2. le premier tileset ImageGen, référence de matière et de couleur ;
3. la grille-guide 16 × 5, référence d'extraction.

Demande finale : conserver les 80 rôles, les raccords et l'occupation exacte du
premier tileset, avec le langage visuel racines, fer sombre, cuivre oxydé,
verre turquoise, mousse et laiton de l'étude ImageGen.

Les deux sorties ImageGen sont conservées comme études. Elles ont été rejetées
comme atlas final parce que le modèle a produit seulement quatre rangées utiles.
Le fichier de production est donc construit par recoloration pixel à pixel de la
géométrie validée du niveau 1, avec la palette issue de l'étude ImageGen. Les
objets ImageGen sont réutilisés seulement dans les cases isolées ; toutes les
cases modulaires conservent exactement le masque du niveau 1.
