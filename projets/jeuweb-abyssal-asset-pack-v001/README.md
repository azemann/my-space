# Jeuweb — Abyssal Techno-Fantasy Asset Pack v001

Second univers visuel autonome pour le jeu : ruines de corail noir, machines en cuivre patiné, énergie cyan et faune bioluminescente.

Le pack est volontairement séparé du mégapack industriel afin de permettre une comparaison artistique et une intégration sélective.

## Organisation

- `sources/terrain` : plateformes et architecture.
- `sources/props` : décor et objets interactifs.
- `sources/enemies` : silhouettes adverses.
- `sources/pickups` : récompenses lisibles.
- `sources/weapons` : familles arme + projectile + impact.
- `catalog` : inventaire et intentions de gameplay.
- `review` : planche de revue.

Tous les PNG sont des sources candidates avec transparence réelle. Ils restent à normaliser selon l'échelle, les pivots et les collisions du projet Godot.
