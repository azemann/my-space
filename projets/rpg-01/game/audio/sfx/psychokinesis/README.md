# Exports psychokinétiques

Ces WAV 48 kHz sont rendus depuis les masters de
`source-art/lmms/psychokinesis/`. Ils ne doivent pas être retouchés directement.

| Export | Événement Godot |
| --- | --- |
| `lift.wav` | arrachement du sol |
| `hold.wav` | maintien en lévitation |
| `throw.wav` | libération de la projection |
| `impact-stone.wav` | retombée d'un objet en pierre |

Les lecteurs emploient le bus `Psychokinesis`, lui-même envoyé vers `SFX`.
